# Frontend

Diretório reservado para a aplicação Angular, usando Bootstrap como base visual.
O workspace Angular será criado diretamente nesta pasta. Ainda não há aplicação,
dependências JavaScript ou comando de execução nesta etapa.

## Escopo inicial

- Layout adaptado ao Android e ao computador.
- Botão `+` para ler o QR Code pela câmera e enviar o conteúdo ao backend.
- Lista de notas pendentes de importação.
- Revisão de todos os produtos, com alertas para informações que precisam de ajuste.
- Continuação da revisão em outro dispositivo e confirmação explícita da importação.
- Dashboard mensal com categorias, produtos, marcas, quantidades e gastos.

As regras de consulta da SEFAZ, classificação e cálculo ficarão no backend.
O acesso local terá HTTPS reconhecido pelo Android para o uso da câmera.
